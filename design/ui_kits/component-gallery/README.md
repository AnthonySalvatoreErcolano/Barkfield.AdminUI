# Component Gallery

One page showing every Barkfield Road web UI component and its key states — buttons, icon buttons, inputs, selects, textarea, checkbox/radio/switch, dropdown menus, badges (status pills), chips (filters/tags), cards, stat cards, data tables (selectable, sortable, compact, empty), pagination, sidebar, tabs, breadcrumbs, alerts, toasts, tooltips and dialogs.

This is the primary reference to hand to Claude Code alongside `readme.md`, `styles.css` + `tokens/`, and `components/`.
