Single-line text field — search boxes, customer details, quantities.

```jsx
<Input label="Email" placeholder="daniella@example.com" />
<Input iconLeft="search" placeholder="Search customers, pups, orders…" size="sm" />
<Input label="Frequency" type="number" suffix="weeks" error="Must be 1–12" />
```

- Labels are uppercase display type; values are Zilla Slab.
- Focus: teal border + soft teal ring. Error: terracotta border + message.
