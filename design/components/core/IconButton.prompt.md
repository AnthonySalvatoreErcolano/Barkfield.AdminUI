Icon-only square button — row actions, toolbar tools, close buttons.

```jsx
<IconButton icon="ellipsis" label="More actions" />
<IconButton icon="pencil" label="Edit" variant="secondary" size="sm" />
```

- Sizes sm 28 · md 36 · lg 44 (use lg for touch).
- `on-brand` for use inside the teal sidebar/top bar.
